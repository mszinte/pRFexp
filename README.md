# pRFexp_fixPos
By :      Marco BEDINI<br/>
Projet :  pRFexp alternative fixation positions project<br/>
With :    Sina KLING & Martin SZINTE<br/>

## Version description
Experiment in which we first use a square full screen 4 directions (left/right/up/down) bar pass stimuli with an attention task to the bar in order to obtain pRF retinotopy of the occipital, parietal, frontal and subcortical structures. Fixation point can be on one of 5 positions 
% (left up, left down, right up, right down, center).

## Acquisition sequences
* 2.0 mm isotropic<br/> 
* TR 1.2 seconds<br/>
* Multi-band 4<br/>
* 60 slices<br/>
