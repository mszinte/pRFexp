# pRFexp_fixPos
By :      Marco BEDINI<br/>
Project :  pRFexp eccentric fixation positions project<br/>
With :    Sina KLING & Martin SZINTE<br/>

## Version description
Experiment in which we first use a square full screen 4 directions (left/right/up/down) bar pass stimuli with an attention task to the bar in order to obtain pRF retinotopy of the occipital, parietal, frontal and subcortical structures. Fixation point can be on one of 5 positions 
% (left up, right up, right down, left down, center).

## Acquisition sequences (same as RetinoMaps)
* 2.0 mm isotropic<br/> 
* TR 1.2 seconds<br/>
* Multi-band 4<br/>
* 60 slices<br/>

## Experiment runner
* run the experiment using main/expLauncher.m
